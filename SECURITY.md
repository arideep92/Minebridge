# Security Policy

The security of MineBridge and its users is important to us.

If you discover a security vulnerability, please report it responsibly.

## Supported Versions

Security updates are provided for actively maintained releases.

| Version | Support Status |
|---------|----------------|
| 1.2.x   | Supported |
| 1.1.x   | Not guaranteed |
| 1.0.x   | Not guaranteed |
| < 1.0   | Not supported |

## Reporting a Vulnerability

If you discover a security vulnerability in MineBridge, please report it privately.

**Do not publicly disclose the vulnerability before it has been investigated.**

You can contact the maintainer through GitHub:

https://github.com/aridrochatterjee

For security-related reports, include:

- A clear description of the vulnerability.
- Steps to reproduce the issue.
- Potential impact.
- Relevant logs or screenshots, if available.
- Any suggested fixes, if applicable.

## What Happens Next?

After receiving a report:

1. The report will be reviewed.
2. The vulnerability will be investigated.
3. Additional information may be requested.
4. A fix may be developed and tested.
5. A security update may be released.

Response and resolution times are not guaranteed.

## Security Best Practices

MineBridge server administrators should:

- Never share their Discord bot token.
- Store credentials securely.
- Avoid committing configuration files containing secrets.
- Keep MineBridge and server software updated.
- Give Discord bots only the permissions they need.
- Restrict access to server configuration files.

## Responsible Disclosure

Please give the maintainer a reasonable opportunity to investigate and address reported vulnerabilities before making them public.

Thank you for helping keep MineBridge secure.
